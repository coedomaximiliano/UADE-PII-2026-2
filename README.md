# UADE - PII

Repositorio público de la cátedra para que los alumnos suban el código de sus trabajos prácticos.

## Organización

El código se organiza por trabajo práctico y, dentro de cada uno, por grupo:

```
TRABAJOS PRACTICOS/
  TP1/
    grupo 1/
    grupo 2/
  TP2/
    grupo 1/
```

Cada grupo tiene una única carpeta compartida por todos sus integrantes.

## Cómo subir tu código

- **¿Primera vez usando Git?** Seguí la [guía paso a paso para alumnos](GUIA-ALUMNOS.md).
- Si ya sabés usar Git, el flujo resumido está en [CONTRIBUTING.md](CONTRIBUTING.md).
