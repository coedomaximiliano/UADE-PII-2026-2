# UADE

Repositorio público de la cátedra para que los alumnos suban el código de sus trabajos prácticos.

## Organización

El código se organiza por trabajo práctico y, dentro de cada uno, por alumno:

```
tps/
  tp1/
    apellido-nombre/
  tp2/
    apellido-nombre/
```
